Términos de Uso

Última actualización: Septiembre 2026

1. Aceptación de los Términos

Al descargar, instalar o usar Bitácora, aceptas estos términos de uso. Si no estás de acuerdo con estos términos, no uses la aplicación.

2. Descripción del Servicio

Bitácora es una aplicación para gestión académica, pensada para carreras (universitarias o similares) donde algunos miembros participan como alumnos y otros como docentes. Permite:

  • Crear y organizar tareas propias por materia, con fechas de entrega y recordatorios
  • Gestionar materias académicas y reuniones
  • Sincronizar datos entre dispositivos, con uso sin conexión
  • Guardar y compartir archivos de estudio en tu propio Google Drive
  • Si sos docente de una carrera: crear tareas oficiales para toda la carrera, revisar y calificar las entregas, tomar asistencia, publicar anuncios y ver un panel con el progreso de cada alumno
  • Si sos alumno de una carrera: ver tus tareas oficiales, tu asistencia, las notas y comentarios que te deje tu docente, y los anuncios de tu carrera
  • Roles y administración: un administrador de la instalación puede asignar o quitar el rol de docente a un miembro de una carrera

3. Cuenta de Usuario

Para usar Bitácora necesitas:

  • Una cuenta de Google válida
  • Tener al menos 13 años de edad
  • Proporcionar información verídica

Eres responsable de mantener la seguridad de tu cuenta y de todas las actividades que ocurran bajo ella.

Si participás como docente de una carrera, sos responsable de usar la asistencia, las notas y los comentarios que dejás de forma veraz y apropiada — esa información la ven los alumnos correspondientes.

4. Uso Aceptable

Te comprometes a:

  • Usar la aplicación solo para fines académicos
  • No crear contenido ilegal, ofensivo o que infrinja derechos de terceros
  • No intentar acceder a cuentas de otros usuarios
  • No usar la aplicación para distribuir malware o spam
  • No realizar ingeniería inversa de la aplicación
  • Si te asignan el rol de docente, no usarlo para acceder a datos de alumnos de carreras a las que no pertenecés
